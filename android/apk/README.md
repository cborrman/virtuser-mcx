# Virtuser MCX APK

The app is built by GitHub Actions (`.github/workflows/build-android.yml`) on every change to `android/`.
The latest build is always at:

https://github.com/cborrman/virtuser-mcx/releases/latest/download/virtuser-mcx.apk

Android 13 or later. Test build, signed with the test key in `android/virtuser-test.keystore`: demo phones only.
